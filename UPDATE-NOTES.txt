ORVION — PREMIUM UPGRADE (v14)

DATA SAFETY (read first)
- Firebase config, collection name ("watchlist"), document IDs and every existing field are unchanged.
- No migration, no bulk write, no delete. Old documents work as they are.
- New OPTIONAL fields are written only when you tap something, and only on that title's existing document:
    completedAt  (number)  set when a title is moved to Watched. Old entries are NOT back-filled.
    progress     (map)     episode tracker: watched{season:[eps]}, totals{season:n}, ongoing, last{s,e}, updated
  Progress is saved with field paths ("progress.watched.2"), so saving Season 2 can never overwrite Season 1.
- Opening the tracker never writes. Duplicate entries are reported, never deleted.
- Orvion has NO Firebase Authentication (the original project doesn't use it). All data is in one shared
  "watchlist" collection protected only by your Firestore rules. Adding auth now would orphan your existing
  documents, so it was deliberately NOT added. Review your Firestore rules before sharing the site publicly.

FEATURES
- Redesign: Liquid Glass + true AMOLED black, Inter typography, new orbit logo, swipe-down sheets,
  smoother motion (spring press/pop, drawn check marks, bars that grow), hero auto-advance, "already in your list" badges.
- Episode tracker: seasons, per-episode toggle, Mark all/Clear season, "up to here" (long-press or Shift-click),
  next episode (S2 E6), overall %, specials, unaired episodes locked, Undo, offline fallback from saved totals.
  Status moves Plan -> Watching on first episode; a prompt offers "Mark as Watched" when a finished series is completed.
- Continue watching (Home) with one-tap "mark next episode".
- Statistics: totals, status, category, episodes tracked, activity (completed/added, months/years), genres, estimated
  watch time, in-progress, recently completed, milestones. Only real data; estimates are labelled.
- Appearance: Dark / Light / System / AMOLED, 7 accents + custom picker, glass slider, density, card style,
  animation intensity (Auto/Full/Subtle/None), 6 presets. Old orvion-theme / orvion-color settings are still honoured.
- Watchlist: title filter, "Recently updated" sort, progress bars, batched rendering for large libraries.
- Add sheet suggests Anime (Japanese animation) / K-Drama (Korean) / Series / Movie automatically.

BUGS FIXED / HARDENED
- offline.html: invalid `font: ... inherit` declaration (button font was ignored).
- manifest: "any maskable" icons were cropped on Android -> separate any + maskable icons.
- Logo: tiny, black-backed raster -> vector mark, correct size in header, favicon, install icon, splash.
- vercel.json: service worker never cached, security headers added.
- Service worker: navigation preload, network no longer abandoned after the timeout, bounded Firebase cache,
  Google Fonts cached for offline, new files precached.
- Firestore reads: Home/Stats/badges share one cached library snapshot (10 min), updated after every write.
- Large libraries: rows capped at 24 with "See all", grids render in batches.

HOW TO DEPLOY
1. Keep a backup of the live project. Copy these files over it (keep your hidden .git folder).
2. Run through Live Server / any HTTP server (not file://) and test: Home, Watchlist, tracker, Stats, Appearance.
3. Commit and push. The service worker (v14) replaces the old cache on the next visit; a "Refresh" toast appears.
